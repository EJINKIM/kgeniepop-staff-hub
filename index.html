🧹 객실 청소 인증 텍스트 만들기

서로 다른 두 사진을 각각 붙여넣고, 객실 버튼을 눌러 청소 완료 인증용 텍스트를 만들어요.
인스펙객실현황에 올리기
이 구역에는 인스펙 완료 객실 사진만 붙여넣기 · 하늘색 셀 + 빨간 객실번호는 * · 연박은 연박으로 분리
📷 인스펙 사진 붙여넣기이 박스를 클릭한 뒤 Ctrl+V 하거나 사진을 선택하세요.
실시간 완성 텍스트 — 항상 직접 수정 가능
버튼을 누르면 자동 반영되지만, 이 칸에 직접 문구를 추가·삭제·수정해도 됩니다.
객실정비방에 올리기

📷 호실 사진 붙여넣기이 박스를 클릭한 뒤 Ctrl+V 하거나 사진을 선택하세요.
