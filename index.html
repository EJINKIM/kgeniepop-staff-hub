🛎️ 객실 보고문 만들기

사진은 크게 보고, 객실 버튼만 톡톡 눌러서 보고문을 만들어요. 자동 인식 없이 확실하게 ✨

📷 사진 붙여넣기 / 불러오기Ctrl+V · 클릭해서 사진 선택 · 드래그 앤 드롭
사진은 분석하지 않고, 크게 띄워 참고용으로만 보여줘요.
① 인스펙 완료 보고
하늘색 + 빨간 객실번호는 *, 연두색은 연박
먼저 상태를 고른 뒤 객실번호를 누르세요. 같은 객실은 한 상태만 가질 수 있어요.
파랑 = * 완료연두 = 연박
실시간 완성 텍스트 — 직접 수정도 가능
② 호실 / 연박 보고
일반 호실은 본문에, 연두색 객실은 연박 아래에
일반 호실을 넣을 때는 호실, 연박 객실은 연박을 선택한 뒤 번호를 누르세요.
분홍 = 일반 호실연두 = 연박
